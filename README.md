***Some Fundamental concepts used in the project***
  *Product Listings and Catalogs:* Organizing products in categories and listings to make it easy for users to browse and select items.

  **Responsive Web Design:** Ensuring the site looks and functions well across various devices, achieved with Tailwind CSS for flexible styling.

  **Client Side Rendering:** React handles the dynamic rendering of content directly on the client’s browser, which enhances speed and user interactivity.

  **Product Details and Reviews:** Displaying detailed information for each product, including images, descriptions, prices, and user reviews.

  **Shopping Cart Functionality:** Allowing users to add items to a virtual cart, review them, and proceed to checkout.

  **User Authentication:** Login and registration features for personalized experiences, order tracking, and secure transactions.

  **Search and Filtering:** Enabling users to search for products and apply filters based on criteria like price, category, and ratings.
